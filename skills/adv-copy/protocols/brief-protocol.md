# Brief Protocol — WRITE-режим adv-copy

Цель Phase A (WRITE): собрать объект `brief` **строго по контракту** `copy-writing-pipeline.js`.
Отсутствие обязательного поля роняет конвейер в `status:'error'` — интервью обязано их закрыть.
Интервью веди на языке пользователя; поле `language` определяет язык генерируемого ТЕКСТА,
а не язык интервью.

## Cap (сообщить пользователю до старта)

Полный WRITE-конвейер = **3 драфта × разные линзы → критика 4–5 советников → синтез**.
Это дороже стандартного VERDICT. Для одного крючка / одной строки / быстрой проверки
заголовка — не гонять конвейер, а взять standalone-советника (`/advisor-sugarman` и т.п.).

## Поля брифа (контракт — ключи ровно эти)

| Поле | Тип | Что собрать | Обязательное |
|------|-----|-------------|:---:|
| `task` | string | Что пишем, одним предложением | ✅ |
| `type` | `'short-form' \| 'landing' \| 'email' \| 'vsl'` | Тип текста (определяет критиков — см. routing-matrix.md) | ✅ |
| `language` | `'uk' \| 'ru' \| 'en'` | Язык готового текста | ✅ |
| `audience` | string | Кто + **их реальный язык/лексика** (дословные фразы, см. ниже) | ✅ |
| `offer` | string | Оффер + пруфы (кейсы, цифры, гарантии — **только реальные**) | ✅ |
| `awarenessStage` | 1–5 | Стадия осознанности по Schwartz (шпаргалка ниже) | ✅ |
| `sophistication` | 1–5 | Искушённость рынка по Schwartz (шпаргалка ниже) | ✅ |
| `cta` | string | Целевое действие | ✅ |
| `constraints` | string | Тон, длина, платформа, запреты | ✅ |
| `swipeFile` | string\|null | Абсолютный путь к `_Свайп-файл.md` (может не существовать — путь всё равно передать) | — |
| `context` | string | Остальное из интервью (гипотезы, история продукта, что уже пробовали) | — |
| `outputName` | string | (вне brief, соседний arg) Имя результата без `.md` | ✅ |

## Вопросы интервью (минимальный проход)

Не переспрашивай то, что уже есть в памяти (`## Profile`) или в исходном запросе.

1. **Что и зачем.** Что за текст, какое одно действие он должен вызвать? → `task`, `cta`.
2. **Тип и площадка.** Где живёт текст? (пост в ленте / лендинг / серия писем / видео-скрипт) →
   `type` + платформа/лимиты в `constraints`. Если неоднозначно — уточни явно, тип определяет критиков.
3. **Аудитория и её язык.** Кто это? Дай **дословно 2–4 фразы**, как аудитория сама называет
   свою боль/желание (из отзывов, переписок, комментариев). → `audience`.
4. **Оффер и пруфы.** Что предлагаем, по какой цене/условиям? Какие **реальные** доказательства
   есть (кейсы, цифры, отзывы, гарантия)? → `offer`. Пруфов нет — так и запиши, не выдумывать.
5. **Стадия осознанности** (шпаргалка ниже) → `awarenessStage`.
6. **Искушённость рынка** (шпаргалка ниже) → `sophistication`.
7. **Тон и запреты.** Тон бренда, чего нельзя (обещания, слова, формат)? Длина/лимиты? → `constraints`.
8. **Язык текста.** UK, RU или EN? → `language`. Для лендингов украинцам в ЕС — `uk` основная, `ru` — transcreation отдельным проходом.
9. **Свайп-файл и имя.** Передать путь к `_Свайп-файл.md`; спросить/предложить `outputName`.

Пропущенное свести в `context`. Гипотезы (то, что пользователь не знает точно) помечать
как гипотезы, а не как факт.

## Правило: реальный язык аудитории > выдуманных формулировок

Копия говорит словами читателя. Если пользователь может дать дословные цитаты аудитории
(как она формулирует боль/желание/возражение) — собрать их в `audience` буквально; конвейер
строит крючки и лид на этой лексике. **Не сочинять формулировки за аудиторию**: выдуманная
«боль клиента» уводит в generic-копию. Нет цитат → отметить в `context` как зону риска
(«язык аудитории — гипотеза»), чтобы синтезатор не выдавал догадку за инсайт.

## Шпаргалка: стадии осознанности (Schwartz, awarenessStage 1–5)

Насколько читатель осознаёт свою проблему и твоё решение. Определяет, с чего начинать текст.

| Стадия | Читатель знает | С чего начинать копию |
|:---:|----------------|------------------------|
| **5 — Most Aware** | Знает продукт, готов купить, ждёт повода | Оффер/цена/дедлайн в лоб, минимум прогрева |
| **4 — Product-Aware** | Знает твой продукт, но не решился | Дифференциация, пруфы, снятие возражений |
| **3 — Solution-Aware** | Знает, что такие решения есть, не знает твоё | Механизм/«почему именно так работает», твоё УТП |
| **2 — Problem-Aware** | Чувствует проблему, не знает решений | Назвать боль точнее, чем он сам → вывести к решению |
| **1 — Unaware** | Не осознаёт проблему | История/факт/провокация; продавать нельзя сразу |

Ниже стадия → длиннее прогрев, тем важнее лид (см. Great Leads в routing-matrix).

## Шпаргалка: искушённость рынка (Schwartz, sophistication 1–5)

Сколько подобных обещаний рынок уже слышал. Определяет, насколько «в лоб» можно обещать.

| Уровень | Состояние рынка | Ход копирайтера |
|:---:|-----------------|------------------|
| **1** | Ты первый с таким обещанием | Простое прямое обещание работает |
| **2** | Есть конкуренты с тем же обещанием | Усиль обещание (больше/быстрее/легче) |
| **3** | Обещания приелись, им не верят | Новый **механизм** — «как именно» это достигается |
| **4** | Механизмы тоже приелись | Усиль/переформулируй механизм, сделай его уникальным |
| **5** | Рынок выгорел, циничен | Идентификация/опыт/новая эмоция, а не обещание в лоб |

Выше уровень → меньше прямых обещаний, больше механизма и свежего угла.

## Выход Phase A

Собранный `brief` (все ✅-поля заполнены) + `outputName` → в args `copy-writing-pipeline.js`.
Неполный бриф не отправлять — конвейер вернёт `error` без работы.
