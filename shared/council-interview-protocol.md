# Council Interview Protocol

Общая интервью-фаза для adv-Decision / adv-product / adv-influence. Исполняется **главной сессией** (AskUserQuestion недоступен субагентам и workflow — платформенное ограничение). Цель: собрать контекст ДО делиберации, дедуплицировать вопросы советников и построить карту «известно/неизвестно», которую получат все советники и validator.

## Когда запускать

- **adv-product / adv-influence** — всегда в Phase A, ПОСЛЕ preflight ростера и сборки SCOPE (harvest'у нужны готовый ростер и существующий WORK_DIR).
- **adv-Decision** — только в ветке COUNCIL после satisfice gate (тривиальные решения за интервью не платят).

## Шаг 0 — Карта известного (KNOWN_MAP)

Из запроса и памяти (`{MEMORY_DIR}/Профили/<совет>.md`; у influence — включая курируемую секцию `## Profile`) собери список уже известных фактов с пометкой источника: «из запроса» / «из памяти». Это вход для фильтра (шаг 2) и секции «Известно» досье (шаг 5).

## Шаг 1 — Harvest (вопросы советников)

```
Workflow({
  name: "council-question-harvest",
  args: {
    query: RAW_QUERY,
    userContext: <контекст из памяти, БЕЗ досье>,
    roster: <post-preflight ростер совета в форме {slug, name, skillPath}>,
    councilType: "decision" | "product" | "influence",
    maxQuestionsPerAdvisor: 3,
    workDir: WORK_DIR      // ТОТ ЖЕ, что у council-ядра: harvest.json уберёт общий rm -rf в Phase C
  }
})
```

- Смэппинг поля `name`: `book (author)` у product/influence, `lensName` у decision.
- Дождись `<task-notification>`; возьми `clusters[]`, `advisorsAnswered`.
- `clusters` пуст, а `rawQuestionCount > 0` (кластеризатор упал) → прочитай `{WORK_DIR}/harvest.json` как fallback; нет и файла → работай без harvest-вопросов.

## Шаг 2 — Фильтр кластеров

Выкинь кластеры, ответ на которые уже есть в KNOWN_MAP (кластеризатор мог пропустить). Оставшиеся отсортируй по `unlockValue` (high → med → low); при равенстве — больше `askedBy` выше.

## Шаг 3 — Интервью (AskUserQuestion, только главная сессия)

- **≤2 батчей × 4 вопроса** (итого ≤8 заданных). Приоритет — high-unlock. Второй батч не запускай, если после первого осталось <2 содержательных кластеров.
- Формат вопроса: `header` из кластера (≤12 симв); текст = `canonicalQuestion` (+1 фраза «зачем», если неочевидно); опции = ≤3 варианта кластера + последней «Не знаю / не важно» (лимит 4 опции; «Other» добавляется автоматически). Рекомендованную опцию — первой с пометкой «(Recommended)», если рекомендация обоснована.
- `multiSelect: true` — где ответы не взаимоисключающие (каналы, платформы, сегменты).
- У adv-Decision первый батч — статические базовые вопросы (см. SKILL.md), harvest-кластеры идут вторым.

## Шаг 4 — Обработка ответов

- Выбран вариант / Other-текст → зона «Выяснено» (Other — дословно).
- «Не знаю / не важно» → зона «Неизвестно (спрошено — пользователь не знает)».
- Кластеры за лимитом 8 → зона «Не спрошено (за лимитом)», только заголовки.

Реестр ответов живёт **только в рамках забега** — в персистентную память не пишется (журналы Phase C работают как раньше).

## Шаг 5 — CONTEXT_DOSSIER

Компактный markdown-блок (Q→A — одной строкой на пару). Шаблон:

```markdown
### CONTEXT DOSSIER (карта контекста забега)
**Известно (из запроса):** …
**Известно (из памяти):** …
**Выяснено в интервью:**
- Q: {вопрос} → A: {ответ} · спросили: {slugs}
**Неизвестно (спрошено — пользователь не знает):**
- {вопрос} · почему важно: {whyItMatters}
**Не спрошено (за лимитом):** {заголовки кластеров через ;}
**Допущения:** {что принимается по умолчанию там, где ответа нет}
**Директива советникам и validator:** зоны «неизвестно» трактовать как РИСКИ — не выдумывать
факты вместо них; в вердикте отразить их в секции слепых зон и указать, как ответ мог бы
изменить рекомендацию.
```

Пустые секции опускай. Итоговый `userContext` для council-ядра = прежний контекст из памяти + CONTEXT_DOSSIER (досье в конце).

## Деградация

| Ситуация | Действие |
|---|---|
| harvest вернул `clusters: []`, `rawQuestionCount: 0` | Всем всё ясно / вопрошатели упали → пропусти шаги 2–4, досье из KNOWN_MAP (+ у Decision — статические вопросы), совет продолжается |
| harvest-workflow умер / нет результата | Ветка «harvest недоступен»: досье из KNOWN_MAP с пометкой «интервью советников недоступно», совет продолжается |
| пользователь ответил «Не знаю» на всё | Все вопросы → «Неизвестно»; совет идёт с честными слепыми зонами |
