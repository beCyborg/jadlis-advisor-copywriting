# Как предложить правку

Этот репозиторий **генерируется** из приватного источника `jadlis-advisors-source` скриптом `tools/split-councils.py`; прямые правки здесь CI отклоняет (`tools/check-generated.py` сверяет хеш с `SHARED_FROM.txt`). Нашли ошибку — откройте issue здесь, правка ляжет в источник и приедет следующим релизом `advisor-copywriting--vX.Y.Z`.

Лицензии на конспекты книг нет — намеренно, см. [NOTICE.md](NOTICE.md). Тексты и код написаны вместе с Claude Code; за содержание отвечает владелец.

## English

This repository is **generated** from the private source `jadlis-advisors-source` by `tools/split-councils.py`; direct edits fail CI (`tools/check-generated.py` compares the content hash with `SHARED_FROM.txt`). Found a problem — open an issue here; the fix lands in the source and ships with the next `advisor-copywriting--vX.Y.Z` release.

No licence on the book digests, deliberately — see [NOTICE.md](NOTICE.md). Text and code are written together with Claude Code; the owner is accountable for the content.
