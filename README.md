# Свой текст перечитан столько раз, что глаз ловит опечатки, а не место, где читатель уходит

Восемь книг по копирайтингу разбирают текст порознь, каждая отвечает только из своей, и возвращают
переписанные фрагменты «было → стало» с тегом приёма — или, во втором режиме, сначала пишут три
драфта разными линзами и собирают финал из лучшего.

```
claude plugin marketplace add https://github.com/beCyborg/jadlis-start.git
claude plugin install advisor-copywriting@jadlis
```

Ключей и платных подписок на сторонние сервисы нет; спросят одно — папку памяти советов
`MEMORY_DIR`, куда лягут готовые тексты, вердикты и журнал прогонов.

![Один текст расходится по восьми книгам, каждая возвращает переписанный фрагмент со своим тегом](docs/img/hero-jadlis-advisor-copywriting.webp)

Текстом: слева твой текст одним куском, справа восемь книжных линз, каждая возвращает не мнение, а
переписанный фрагмент с тегом приёма, и всё это сходится в один файл.

Это моё рабочее место, выложенное как есть, а не продукт: чем перестал пользоваться — убрал.

## Было → стало

| Руками | Чатом с ИИ | Этим плагином |
|---|---|---|
| **Кто читает текст перед публикацией.** Читает тот же человек, который его написал: правится то, что заметнее, а не то, что мешает продать. | Отвечает один голос и подхватывает рамку вопроса: спросил про заголовок — получил про заголовок. | Восемь книг разбирают текст параллельно и не видят ответов друг друга; сводит их в один вердикт отдельная роль-валидатор. |
| **Откуда взялась правка.** Правка приходит формулировкой «мне так кажется» — спорить не о чем. | Правка звучит уверенно, а на чём она стоит, не показано. | У каждого приёма стоит тег вида `[ADW:xx]` или `[BTA:xx]` — он указывает на блок конспекта внутри плагина, по которому правку можно открыть и оспорить. |
| **Что делают с тем, в чём книги сошлись.** Сходство мнений неоткуда взять: источник один. | Согласие с собой добавляется на каждом уточняющем вопросе. | Совпавшие и спорные утверждения уходят к скептикам, чья задача — опровергнуть; опровергнутое не попадает в раздел «Что усилить». |
| **Возраст книжного совета.** Пример из эпохи почтовой рассылки читается как сегодняшний: в книге не написано, что он протух. | Эпохи смешиваются в одном абзаце. | У каждой из восьми линз записан её известный скос, валидатор снижает вес и печатает Bias flags: механику Schwartz переносит, кейсы его эпохи не цитирует как актуальные; крен Cashvertising в страх дисконтирует там, где тон мягкий. |
| **Как рождается новый текст.** Пишешь один драфт и правишь его же — сравнивать не с чем. | Второй вариант оказывается тем же текстом другими словами. | Режим написания пишет три драфта разными линзами — формула прямого отклика, лид под стадию осознанности, эмоциональное ядро Life-Force 8, — критики по типу текста ставят оценку всем трём, синтезатор собирает финал из лучших кусков. |

## Как это работает

![Текст уходит в восемь линз, спорное проверяют скептики, валидатор пишет вердикт с переписанными фрагментами](docs/img/how-jadlis-advisor-copywriting.webp)

На входе — готовый текст (режим VERDICT) или бриф на новый (режим WRITE).
Внутри — восемь книжных линз порознь, скептики против совпавших и спорных утверждений, а в режиме
написания — критики, подобранные под тип текста.
На выходе — файл в папке памяти: вердикт с переписанными фрагментами либо готовый текст.

Текстом: текст или бриф → восемь линз порознь → опровержение совпавшего скептиками → синтез одной
ролью → файл в папке памяти.

Выбирает режим сам скилл: флаг `--verdict` или `--write` перебивает всё, иначе решает глагол
(«оцени», «разбери», «что не так» → VERDICT; «напиши», «сделай», «перепиши» → WRITE), а при
неоднозначности он спросит кнопкой.

**VERDICT.** Перед запуском совет проверяет, какие линзы на месте, и считает кворум — шесть из
восьми; ответило меньше, кворум не набран, и синтеза не будет. Дальше линзы отвечают параллельно,
куратор выделяет из их ответов самые решающие утверждения, каждое атакуют скептики по отдельности,
и большинство голосов ставит метку SUPPORTED, CONTESTED или REFUTED. Валидатор взвешивает советы по
четырём критериям — насколько домен книги отвечает за этот тип текста, конкретность правок,
подтверждение другими книгами, самооценка советника, — применяет Bias-поправки и пишет вердикт:
SWOT самого текста, «Что усилить» с приоритетами, «Чего НЕ делать», таблицу переписанных фрагментов
«было → стало» с тегом приёма, карту консенсуса и рейтинг советников.

**WRITE.** Начинается с бриф-интервью: что за текст и какое одно действие он должен вызвать, тип
(short-form, лендинг, email, VSL), язык готового текста (украинский, русский или английский —
отдельно от языка разговора), аудитория дословными её фразами, оффер с настоящими пруфами, стадия
осознанности и искушённость рынка по Schwartz, целевое действие и ограничения. Дальше три драфта
параллельно, критика по таблице маршрутизации — короткая форма идёт к Heath, Berger, Cashvertising
и Great Leads; лендинг к Schwartz, Sugarman, Cashvertising и Cialdini; письмо к Bly, Great Leads,
Sugarman и Cialdini; VSL берёт пятерых, — и синтез. Файл на выходе содержит финальный текст,
альтернативные крючки, список применённых приёмов с тегами и сводку критики: что взято, что
отклонено и почему.

Восемь советников — это The Adweek Copywriting Handbook (Sugarman), Cashvertising (Whitman),
Breakthrough Advertising (Schwartz), The Copywriter's Handbook (Bly), Great Leads
(Masterson/Forde), Influence (Cialdini), Made to Stick (Heath & Heath) и Contagious (Berger).
Рядом с ними лежит слой классики без отдельного советника — Hopkins, Caples, Kennedy, — он
подмешивается всем типам текста; короткая форма дополнительно получает линзу Hook Point, письмо —
Boron Letters.

## Установка и первый запуск

**а) Текст для вставки агенту.** Скопируй целиком в чат Claude Code:

```
Ты — установщик. Поставь на этот Mac плагин advisor-copywriting из маркетплейса jadlis.
Выполни ровно эти команды, дословно, ничего не сокращая:
1. claude plugin marketplace add https://github.com/beCyborg/jadlis-start.git
2. claude plugin install advisor-copywriting@jadlis
3. claude plugin list — покажи мне строку про advisor-copywriting и его версию.
Ключи этому плагину не нужны. При включении он спросит одну настройку — MEMORY_DIR,
папку, куда лягут готовые тексты и вердикты: путь ввожу я сам, ты его не придумываешь.
Перед каждой командой покажи её мне целиком и дождись «да». Сказал «нет» — не выполняй,
скажи, что именно пропустил, и иди дальше.
Команда вернула ошибку — остановись, покажи вывод, к следующей не переходи.
```

**б) Команды руками.**

```
claude plugin marketplace add https://github.com/beCyborg/jadlis-start.git
claude plugin install advisor-copywriting@jadlis
claude plugin list
```

Первая команда ничего не ставит — она добавляет маркетплейс. Ставит только вторая, и снимается
она одной строкой: `claude plugin uninstall advisor-copywriting@jadlis --keep-data`.

Папку памяти можно задать прямо в установке — `claude plugin install advisor-copywriting@jadlis
--config MEMORY_DIR=~/advisors-memory`. Основной путь — диалог настроек, который Claude Code
показывает при включении плагина. Поменять путь потом можно только переустановкой с `--config`:
на уже установленном плагине этот флаг молча ничего не меняет (проверено 07.09.2026). При первом
запуске совет сам разворачивает в этой папке скелет — журналы, профиль и свайп-файл — и
рассказывает, что появилось; существующие файлы он не трогает. Путь остался незаданным — совет
останавливается на первом шаге и в рабочую папку не пишет.

**в) Короткая команда.** Открой Claude Code в папке, где работаешь, и набери:

```
/advisor-copywriting
```

Не находится — сверь имя строкой `claude plugin list`. Дальше либо вставь текст на разбор, либо
опиши, что нужно написать; режим можно задать явно — `/advisor-copywriting --verdict` или
`/advisor-copywriting --write`.

## Границы, стоимость, обновление

**Чего не делает.** Не разбирает звонки, не ведёт застрявшую сделку и не пишет письмо конкретному
клиенту в живой сделке — аутрич, фоллоу-ап после демо, коммерческое предложение уходят в
`advisor-sales`. Не пишет продающий вебинар и сцену: этот контур отложен, совет откажется прямо на
входе. Не ходит в интернет и не проверяет факты: линзы отвечают только из конспектов, лежащих
внутри плагина, свежих данных о твоём рынке у них нет. Не выдумывает пруфы — цифры, кейсы и
гарантии берутся из брифа, и если их нет, так и остаётся. Не пополняет свайп-файл сам: победивший
крючок туда заносится только после твоего подтверждения. И не пишет ничего за пределами папки
памяти.

**Что нужно.** Ключей нет, платных сервисов нет, MCP-серверов плагин не поднимает. Нужен только
Claude Code с включёнными плагинами и подписка, из квоты которой идут субагенты. Единственная
настройка — `MEMORY_DIR`, обычная папка с markdown-файлами; содержимое приватное, поэтому место
выбирается с оглядкой на синхронизацию и бэкапы, и в публичный git эта папка не кладётся.

[уточнить] — минимальная версия Claude Code в репозитории не зафиксирована.

**Порядок расхода токенов.** Прогон тяжёлый: десятки субагентов из твоей квоты — восемь линз,
куратор, скептики на каждое проверяемое утверждение, валидатор; режим написания дороже, потому что
к этому добавляются три драфта и критики. Исчерпанное сессионное окно валит фан-аут целиком: не
«часть линз ответила», а ноль и вердикта нет, — поэтому перед стартом стоит посмотреть остаток
окна. Несколько советов подряд в одно окно не помещаются. Для одного крючка или проверки одного
заголовка совет запускать не надо: скилл прочитает нужную линзу и ответит сам.

**Правки — только в источнике.** Репозиторий генерируется из приватного источника, а CI сверяет
хеш содержимого со `SHARED_FROM.txt`: прямая правка здесь падает на проверке. Нашёл ошибку —
issue сюда, исправление приедет следующим релизом.

**Проверено там, где я работаю:** мой Mac, моя подписка. Где ещё это работает — [уточнить].

**Условия использования.** Лицензии нет: все права сохранены за автором. Читать и
пользоваться лично можно. Коммерческое использование, переиздание и включение в свои
продукты — по договорённости со мной.

Конспекты книг внутри плагина — производные работы; что с ними можно и чего нельзя, разобрано в
`NOTICE.md`.

**Обновление.** У стороннего маркетплейса авто-обновление на твоей стороне выключено: пока не
запустишь первую команду, у тебя остаётся та версия, которую ты поставил.

```
claude plugin marketplace update jadlis
claude plugin update advisor-copywriting@jadlis
claude plugin list
```

Переустановка, если что-то встало криво:

```
claude plugin uninstall advisor-copywriting@jadlis --keep-data && claude plugin install advisor-copywriting@jadlis
```
