# Журнал решений

Ставки совета `adv-Decision`. Append-only: запись создаётся в момент решения, поле «Исход»
заполняется позже, при пересмотре. Пустое поле лучше выдуманного.

Смысл журнала — оценивать **качество решения** отдельно от **качества исхода**: хорошее решение
может дать плохой исход, и наоборот. Без записанной заранее ставки эти две вещи не различить.

Формат записи:

```markdown
## ГГГГ-ММ-ДД — краткое название решения

- **Решение:** одной строкой
- **Выбрано:** что выбрано и какие альтернативы отклонены
- **Среда:** высокая валидность + быстрая обратная связь | низкая валидность + отложенная
- **Предсказанные исходы (ставка):** исход A: ~P% · исход B: ~P%
- **Убийственный сценарий из пре-мортема:** самый вероятный режим отказа
- **Пересмотр:** 3 мес → дата · 6 мес → дата · 12 мес → дата
- **Цитаты:** [PREFIX:CODE], [PREFIX:CODE]
- **Исход (заполняется при пересмотре):** _ждёт_
```
