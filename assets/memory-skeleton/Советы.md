# Советы директоров — хаб

> [!warning] Приватная зона
> Здесь лежат вердикты, профили и журналы. Не втягивать эту папку в экспорты, публикации
> и публичные репозитории. Агентам и скриптам, которые обходят папки по маске, — исключить.

## Что это

Восемь советов: каждый разбирает запрос набором книжных линз параллельно, скептики проверяют
утверждения по одному, валидатор взвешивает мнения и пишет один вердикт файлом.

| Команда | О чём |
|---|---|
| `/advisor-decision` | трудное решение: satisfice-гейт, 5 линз, роутер среды, журнал ставок |
| `/advisor-product` | продукт: PMF, цена, юнит-экономика, ниша, отток |
| `/advisor-influence` | медийность: аудитория, каналы, контент, позиционирование |
| `/advisor-sales` | продажи: разбор звонка, застрявшая сделка, оценка артефакта, письмо |
| `/advisor-copywriting` | тексты: оценка готового текста или конвейер написания |
| `/cognitive-biases` | скан искажений в конкретной ситуации |
| `/robert-greene` | силовая динамика, конфликт, карьерный манёвр |
| `/nupp` | диагностика проекта по шести универсальным принципам |

## Что где лежит

```
Решения/           вердикты adv-Decision
Продукт/           вердикты adv-product
Медийность/        вердикты adv-influence
Продажи/           вердикты adv-sales
Копирайтинг/       готовые тексты adv-copy
Журнал советов.md  по строке на прогон, append-only
Журнал решений.md  ставки adv-Decision и даты пересмотра
Профили/           профиль и журнал сессий каждого совета
Звонки/            транскрипты — только по явному подтверждению
Свайп-файл.md      удачные крючки и формулировки
_runs/             артефакты текущих прогонов, удаляются после записи вердикта
```

## Правила

1. Журналы только дописываются. Ошибочный вердикт остаётся с пометкой — иначе на промахах
   нельзя учиться.
2. Секция `## Profile` в файлах `Профили/` курируется человеком: советы её читают, но
   не переписывают.
3. Полный совет — это десятки вызовов модели. Для одного вопроса он избыточен.
