# Журнал советов

Append-only. По строке на прогон, новые дописываются вниз.

Формат: `- ГГГГ-ММ-ДД · <совет> · <режим, если есть> · <имя файла> — <итог одной строкой>`

Пример:

```markdown
- 2026-01-31 · adv-product · Ценообразование подписки — поднять цену на 40 %, старую когорту не трогать
- 2026-02-03 · adv-sales · CALL · Разбор первого звонка — не выяснена цена бездействия, три хода на следующий
```
