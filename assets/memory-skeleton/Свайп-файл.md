# Свайп-файл

Удачные крючки, заголовки и формулировки — свои и чужие. Пополняется **только по явному
подтверждению**: ни один совет не пишет сюда сам.

Секции по типу текста и языку: `## short-form / ru`, `## landing / en`, `## outreach / ru` и т. д.
Под каждым крючком — одна строка, почему он сработал (или не сработал).
